Frequently Asked Questions

Straightforward answers about using disposable email on {{ domain }}. If something isn’t covered here, feel free to reach out.

What is temp mail / disposable email?

Temporary email is a short-lived address you use instead of your real one. You create an address (for example demo@{{ domain }}), receive messages in a web inbox, and discard it when you’re finished. It’s ideal for sign-ups, one-time codes, and testing without risking your personal inbox.

Do I need to create an account?

No. GGNoob Temp Mail works without registration. Choose a name or accept a random one, copy the address, and open the inbox. There is no password and no profile stored under your identity.

How long do emails stay in the inbox?

Messages are temporary. Retention depends on the underlying mail infrastructure (typically up to several days). Treat the inbox as short-term storage: read what you need, then assume the content may disappear. Do not use this service for important long-term correspondence.

Is it really free?

Yes. Creating addresses and reading messages is free. The site may display advertisements (via Google AdSense or similar) to cover hosting costs. There are no hidden “premium” requirements for basic use.

Can I choose my own address?

Yes. On the home page enter any allowed name (letters, numbers, dots, underscores, plus, hyphen) and you’ll get name@{{ domain }}. If the name is already in use by someone else at that moment, you’ll still see the same public mailbox — so pick something unique if you want privacy for that session.

Is my data private?

We do not require personal information to use the service. Mailboxes are accessible to anyone who knows the address, so never use a temporary address for anything sensitive (banking, medical, passwords you care about long-term). See our Privacy Policy for how we handle technical data such as logs.

Why didn’t I receive an email?

A few common reasons: the sender blocked disposable domains, the message is still in transit, or the address was mistyped. Wait a minute and hit Refresh. Also check that you copied the full address including @{{ domain }}.

Can I send emails from this address?

No. This is a receive-only temporary inbox. You cannot send or reply from @{{ domain }} addresses. Use it only for incoming verification messages, newsletters you don’t want long-term, or testing.

Is this service allowed for AdSense / monetization?

The website itself is a legitimate utility service with clear terms, privacy policy, and original content. We aim to comply with advertising network policies (no prohibited content, clear navigation, real value for users). Final approval always rests with the ad network.

How do I report abuse?

If you believe an address on this domain is being used for harmful activity, please contact us via the Contact page with details. We take reports seriously within the limits of a public temporary-mail system.
